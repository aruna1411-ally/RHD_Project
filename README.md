# AI-Based Early Rheumatic Heart Disease Screening

## An Explainable Multimodal Deep Learning Framework for Early RHD Screening, Severity Classification and Intelligent Clinical Decision Support

### Overview
This project aims to develop an AI-based framework for early Rheumatic Heart Disease (RHD) screening using multimodal patient information.

The proposed system combines:
- **ECG (Electrocardiogram):** Cardiac electrical activity.
- **PCG (Phonocardiogram):** Heart sound recordings.
- **Clinical data:** Patient characteristics, symptoms, blood pressure and relevant medical history.

### Proposed Workflow
1. Data collection and preprocessing.
2. Feature extraction from ECG, PCG and clinical data.
3. Attention-based multimodal feature fusion.
4. Severity classification into Healthy, Mild RHD, Moderate RHD and Severe RHD.
5. Explainability using SHAP and LIME.
6. Clinical decision-support information for monitoring, referral and follow-up.

### Technology Stack
- Python
- Deep Learning
- ECG and PCG Signal Processing
- Multimodal Learning
- SHAP and LIME
- Streamlit (for the application interface, if used)

### Project Status
Under development.
